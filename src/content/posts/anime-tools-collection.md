追番不只是「打开视频网站」。从「这季有什么新番」到「这张截图出自哪部」，再到「本地文件怎么放」，一套顺手的工具能省很多时间。

这篇按使用场景整理，都是我长期在用的类型，尽量选免费/跨平台的。



## 一、追番管理与评分

| 工具 | 用途 | 平台 |
|---|---|---|
| **Bangumi 番组计划** | 中文追番记录、评分、每日放送 | Web / App |
| **AniList** | 英文资料、评分、追番列表、日历 | Web / App |
| **MyAnimeList（MAL）** | 老牌资料库，评分样本大 | Web / App |

用法建议：只选一个当主记录（中文用户推荐 Bangumi），另外两个用来查资料和交叉参考评分。

## 二、新番日历

- **Bangumi「每日放送」**：按星期看今天更新什么。
- **AniList Airing**：按季度/日期筛选。
- **livechart.me**：可视化新番表，按平台/类型筛选。
- **AniChart**：按热度排序的新番表。

季初花 10 分钟把想看的加入「想看」，之后每周照着日历看就行。

## 三、资料与百科

- **萌娘百科**：角色、梗、作品资料，中文最全的二次元百科之一。
- **AniDB**：制作人员、放送记录细。
- **Wikipedia / 各作品官网**：核实放送时间、制作公司。

## 四、找图与图片处理

- **Pixiv**：同人图主阵地，按 tag 搜。
- **SauceNAO**：以图搜番/搜画师，准确率高。
- **ascii2d**：SauceNAO 的补充，偏二次元图。
- **waifu2x**：老图/低清截图放大，救急好用。

## 五、本地播放与媒体库

- **PotPlayer**（Windows）：功能全，字幕/音轨支持好。
- **VLC**：跨平台万能播放器。
- **mpv**：轻量、可配置，进阶用户首选。
- **IINA**（macOS）：mpv 内核，界面友好。
- **Jellyfin / Plex**：把本地动画整理成媒体库，多设备观看（只管理自己合法拥有的内容）。

## 六、字幕相关

- **Aegisub**：字幕制作/调整时间轴，进阶工具。
- 日常观看优先用**官方字幕**或**授权字幕**，外挂字幕注意来源。

## 七、社区与资讯

- **B站**：番剧、PV、UP 主解说。
- **知乎 / NGA**：讨论、避雷、推荐。
- **Reddit r/anime / Discord**：英文社区，新番讨论热闹。

## 八、把这些收进一个入口

工具分散在各处很麻烦。我把常用的追番、资料、工具类网站整理在 [bm.arley.cn](https://bm.arley.cn/)，按分类放好，后台每天自动检测失效链接，点开就能用。

## 九、怎么组合使用（我的日常流程）

1. **季初**：用 livechart.me 看新番表，在 Bangumi 标记「想看」。
2. **每周**：Bangumi「每日放送」确认更新，去正版平台观看。
3. **看完**：回 Bangumi 打分，写一句短评。
4. **找图**：SauceNAO 查出处，Pixiv 收原图。
5. **本地**：下载的文件用 Jellyfin 归档，多设备观看。

工具不用多，**一个记录 + 一个日历 + 一个播放器**就够。关键是固定用同一套，别每个季度换。

## 十、常见问题（FAQ）

**Q：这些工具都要注册吗？**
不强制。Bangumi / AniList 注册后才能记录和评分；查资料不登录也能看。

**Q：哪个评分最可信？**
没有绝对可信，建议看多个平台的分布。Bangumi 偏中文口味，MAL 样本大，AniList 年轻用户多。

**Q：需要特殊网络吗？**
列表里的中文工具（Bangumi、萌娘百科）不需要；海外工具视网络情况而定。
